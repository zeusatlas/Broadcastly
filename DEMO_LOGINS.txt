BROADCASTLY — DEMO SIGN-IN ACCOUNTS
===================================

How to sign in
--------------
1. Open the app and enter the EMAIL and PHONE NUMBER from the list below.
2. A 6-digit code is "sent" by SMS. SMS is not connected yet, so the code is
   printed in the API server's terminal (look for "SMS to ...").
   Whoever runs the API reads the code out to the person signing in.
3. The code expires after 3 minutes. A session lasts 24 hours.

There are no passwords. These are test accounts with made-up data only.
